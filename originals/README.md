# Предоставленные исходники

42 BIN/XML из архивов и вложений владельца сайта: основные ресурсы Garden/Graveyard, общие CoOps-префабы и дополнительные Graveyard-слои. Полный allowlist, размеры и SHA-256 — `manifest.json`. Это предоставленные экспорты, а не независимо сертифицированная официальная поставка.

Каждая страница встраивает пять необходимых BIN; остальные исходники хранятся для разбора, не патчатся и не включаются автоматически в результат. Рабочие профили: `data/garden-profile.json`, `data/graveyard-profile.json`.

По запросу владельца файлы включены в пакет сайта. Публичный GitHub/Pages делает их доступными всем, в том числе из base64 HTML. Перед публикацией требуется проверить права на распространение игровых данных. Никакие права на них проект не предоставляет. Не добавляй другие выгрузки, сгенерированные моды или личные файлы без отдельного запроса.
