# Оригиналы, добавленные по запросу владельца сайта

Пять пар BIN/XML из предоставленного архива `ОРИГИБИН И ХМЛ.zip`. Размеры и SHA-256: `manifest.json`. Это предоставленные пользователем экспорты, а не независимо подтверждённая официальная поставка.

Три BIN генератора дополнительно сверяются с точным профилем `data/bin-schema.json` и встраиваются в HTML при сборке. ChallengeSelector, RewardSpin и XML хранятся для разбора, но не редактируются текущим генератором и не добавляются в выходной ZIP автоматически.
