# Только локально

Помести сюда оригинальные экспорты из своей копии игры и результаты диагностики. Все файлы этой папки, кроме README, исключены из Git. Полных игровых BIN/XML в архиве нет.

Список известных оригиналов: `reference/game-originals-manifest.json`. Проверь их командой `python scripts/check_originals.py local-game-files`.

Не перемешивай оригиналы, Test06, Test07 и новые сборки. Используй подпапки по версиям и сохраняй SHA-256. Перед коммитом проверь `git status --short` и `git diff --cached --name-only`; `.gitignore` не убирает ранее отслеживаемые файлы.
