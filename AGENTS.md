# Вход для агента

Это двухрежимный редактор Time Park: `index.html` (Garden) и `graveyard.html` (Graveyard). Есть GUI и JSON, локальная экспериментальная генерация **пяти BIN выбранного режима**, не FBMOD.

1. Прочитай `README.md`, `docs/OPS-EDITOR.md` и `skills/maintain-timepark-planner/SKILL.md`.
2. Правь `src/`, каталог/профили генерируй `scripts/generate_ops_profiles.py`. Не редактируй только готовые HTML.
3. Пересобери обе страницы `python scripts/build.py`; выполни команды тестов из README. Проверяй UI на desktop/mobile.
4. Не переименовывай прежний Garden localStorage-ключ. Отделяй планы режимов, служебную Graveyard Wave00 и игровой выбор волны 1.
5. Фото не отражать. Правки меток — только x/y; GUID/world неизменны. Axx не является штатным SpawnID.
6. Selector/RewardSpin общие. Не добавляй instant-complete обход под видом безопасного отключения: прошлый эксперимент сопровождался зависанием таймера. NoKnockouts — реальное задание, не no-challenges.
7. Сверяй полные семантические различия через `verify_generated.py`, не только пару ожидаемых полей. Не объявляй runtime-успех по XML.
8. Явное исключение владельца: 42 baseline BIN/XML из `originals/manifest.json` и пять встраиваемых в каждую страницу BIN разрешено включать в пакет. Перед публичной публикацией требуется проверка права на игровые данные. Другие выгрузки, тестовые выходы, FBMOD/FBPROJECT и local-game-files не публикуй автоматически.
9. Не пушь/не развёртывай без запроса и доступа. Зафиксируй реально выполненные проверки. Общие ресурсы и два конфликтующих мод-пакета не должны скрываться от пользователя.

`docs/ARCHITECTURE.md` хранит архитектурную основу прежнего планировщика; при расхождениях приоритет текущему `OPS-EDITOR.md`. `reference/original-site/` и `data/bin-schema.json` — исторические эталоны, не текущая схема двух режимов.
