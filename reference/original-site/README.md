# Исходники до коррекции Рима/Центра

Сохранён исторический срез `app.js`, `template.html`, `photo-layout.json`. Разметка в нём содержит обсуждавшиеся ошибки: это эталон сравнения, а не версия для публикации.

Оригинальные фотографии не дублируются: они лежат в `assets/maps/`, их контрольные суммы — в `reference/map-assets.json`. Текущий каталог — в `data/catalog.json`. Исходный каталог уже содержит отображаемые справочные названия, а не является полной выгрузкой игры.

Не переписывай этот эталон при новой правке. Рабочие файлы — `src/` и `data/photo-layout.json`. Сборка не использует эту папку; тесты используют её только для проверки осознанных перемещений меток.
