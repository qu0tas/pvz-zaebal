# Экспериментальный генератор пяти BIN

Действующая документация: [OPS-EDITOR.md](OPS-EDITOR.md). С версии двух режимов каждая страница использует отдельный точный профиль и пять встроенных оригиналов, а не прежние три.

## Граница записи

1. AISpawnGrid: существующий метод 100xx для явно выбранных A-точек. Добавляются Int32-константы и property bindings, обновляются смещения/счётчики/длина/выравнивание. Исходные импорты и размещения сохраняются, геометрия не перемещается.
2. WaveTree выбранного режима: сужается Waves выбранной группы при конкретном составе, сохраняется корневой список; назначаются ID и дистанционные фильтры выбранных подгрупп; NumMainSpawnPoints=1 для явной точки. Дополнительно меняются только заданные min/max и StartDelayTime.
3. WaveLogic: перенаправляются распознанные старты игровых волн 1–10. Служебные события сохраняются, включая Graveyard Wave00 и эвакуацию. Остальная внешняя логика не отключается.
4. ChallengeSelector: оригинал либо 20 запросов направлены в существующее условие без подмены завершения/сброса. Это не no-challenges.
5. RewardSpin: оригинал либо взвешенный выбор символов в двух исходных ветках; остальные объекты и связи неизменны.

Вход проверяется по точному размеру, SHA-256 и структуре. Не отключать проверки ради совместимости с другим экспортом. Новая версия — новый проверенный профиль. Рабочие буферы копируются; встроенные оригиналы не перезаписываются. Загрузка с диска не отправляет данные на сервер. Публичный HTML содержит встроенные исходники по запросу владельца.

## Сборка и тесты

```bash
python scripts/generate_ops_profiles.py --check
python scripts/build.py
python scripts/build.py --check
python -m unittest discover -s tests -v
node tests/bin_builder.cjs
node tests/ops_profiles.cjs
python scripts/verify_generated.py artifacts/ops-tests/garden
python scripts/verify_generated.py artifacts/ops-tests/graveyard
python scripts/browser_ops_smoke.py --browser /path/to/chromium
```

Последний тест требует дополнительно Python Playwright и Chromium. Игра/Frosty не запускаются. Контрольные суммы, семантическое совпадение и валидный XML — не гарантия правильного поведения движка. Не писать «исправлено в игре», пока пользователь не проверит.
